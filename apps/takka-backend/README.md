# Takka Backend

NestJS API forked from `apps/backend` (`postiz-backend`). Same structure; evolve independently for Takka.

## Scripts

```bash
pnpm --filter takka-backend run dev
pnpm --filter takka-backend run build
pnpm --filter takka-backend run start
```

Uses root `.env`. Alias: `@gitroom/takka-backend/*` → `apps/takka-backend/src/*`.
